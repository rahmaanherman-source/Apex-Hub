# APEX Predictive Science Engine

APEX scientific intelligence architecture for geological, geospatial, environmental, infrastructure, and predictive workloads.

DATA → ONTOLOGY → SPATIAL MODEL → PHYSICS → INFERENCE → VERIFICATION → HUMAN REVIEW → AUDIT

## Truth states
DEFINED, MEASURED, DERIVED, PREDICTED, SIMULATED, FRONTIER, INSUFFICIENT_DATA, VERIFIED, REJECTED, HUMAN_REVIEW_REQUIRED.

A prediction is not a measurement. A derived value is not a direct observation. A confidence field is not calibrated confidence. A physics constraint is not proof of truth.

## Current status
This directory is an architecture and contract skeleton. No scientific dataset, trained model, calibrated confidence model, or production scientific validation is claimed here.

Unknown information must remain explicit. The system must prefer INSUFFICIENT_DATA or HUMAN_REVIEW_REQUIRED over fabricated certainty.
