## Priority filter

Use:

**BUILD NOW / TEST FIRST / RESEARCH / PRESERVE / ARCHIVE**

based on value, novelty, relevance, leverage, evidence, future value, execution cost, risk, and time to real-world test.

## Completion rule

A task is not complete because a file exists. It is complete only when the required behavior is implemented, tested, and—when applicable—deployed and externally verified.

Unfinished work remains an open loop. New work never silently cancels it.
