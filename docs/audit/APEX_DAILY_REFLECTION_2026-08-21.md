### 5. UI Verification Chain

A UI control is not implemented merely because a button, toggle, card, or screen exists.

Required operational chain:

```text
UI
→ Action
→ Capability
→ Provider
→ Result
→ Evidence
```

A decorative control, simulated status, or unverified provider claim cannot be promoted to implemented capability.

### 6. Manual-First is Part of the Memory Model

When authoritative manuals/documentation are reasonably accessible, APEX consults them before operation.

Documentation informs operation but does not prove successful implementation.

### 7. Current Architecture Boundary

```text
LAW = what must be true
MEMORY = what durably matters
RUNTIME = what is true / happening now
EVIDENCE = why a claim is trusted
ARCHIVE = historical source material
```

The Platform Registry is a durable reference/index. Live access state, detailed implementation state, metrics, credentials, and transient execution state remain in authoritative runtime systems.
