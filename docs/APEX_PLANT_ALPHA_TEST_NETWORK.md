# APEX Plant Alpha Test Network

## Purpose

The first real testers should be people who genuinely care for plants, not only general software testers.

Initial alpha target:
- User's wife as first primary tester
- Her plant-knowledgeable friends as early alpha testers
- At least one experienced plant-care person / nursery-connected tester when available

## Capture

For each tester record only the minimum information needed:
- experience level
- plant specialties
- indoor/outdoor focus
- number/type of plants they care for
- gardening activities they actually perform
- most-used features
- confusion/friction points
- requested features
- defects
- ideas that materially improve plant-care workflows

## Test principle

Do not optimize from speculation alone. Observe real plant people using the product.

Primary questions:
1. Can a first-time plant user understand the landing experience without explanation?
2. Can an experienced gardener move quickly without being buried in menus?
3. Does AI reduce work instead of adding another chatbot screen?
4. Does the product make people want to return tomorrow?
5. Does the product help users take a real action, not merely consume information?

## Feedback loop

TESTER → REAL TASK → OBSERVED FRICTION → BOTTLENECK → DESIGN/ENGINEERING CHANGE → RE-TEST → VERIFIED IMPROVEMENT

## Community expansion

After the initial small circle, recruit local:
- plant clubs
- independent growers
- nursery staff
- garden educators
- plant traders
- propagation specialists
- small garden-care businesses

Recruitment should prioritize demonstrated plant activity and useful experience, not follower count alone.
