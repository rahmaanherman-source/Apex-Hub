# APEX UI Principles

## Mission

Production first.

Function before appearance.

A beautiful system that does nothing is unfinished.

A working system can always be refined.

---

## UI Rules

Do not block implementation because of colors.

Do not hardcode color values.

Use theme tokens throughout the application.

Support multiple themes.

Examples:

- Green
- Gold
- Blue
- Dark
- Light

Future themes should require configuration only.

---

## Priority Order

1. Functionality
2. Stability
3. Performance
4. Security
5. User Experience
6. Appearance
7. Branding

---

## Visual Standard

The interface should look:

- Clean
- Modern
- Premium
- Fast
- Consistent
- High quality

Color is configurable.

Quality is mandatory.

---

Every screen should remain production-ready regardless of the active theme.
