## Important distinction

The post's wording **"supports every language"** is marketing shorthand, not a literal technical guarantee. VS Code supports a very large range of languages, but language support is often provided by extensions and external toolchains. For example, C++ support requires a compiler/debugger toolchain outside the C++ extension, and Rust requires Rust tooling plus `rust-analyzer`. Java requires a JDK and Java extensions. citeturn0search1turn0search6turn0search7

Therefore APEX should record:

**VS Code = broad multi-language workspace and extensibility platform**

not:

**VS Code = every compiler/runtime is built in.**
