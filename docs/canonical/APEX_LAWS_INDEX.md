## Binding execution order

```text
LOAD LAW
→ LOAD MEMORY
→ READ AUTHORITATIVE MANUAL / DOCUMENTATION
→ UNDERSTAND WHOLE SUBJECT
→ CHECK ESTABLISHED KNOWLEDGE
→ CHECK CAPABILITY REGISTRY
→ COLLECT EVIDENCE
→ ASSIGN CONFIDENCE
→ IDENTIFY TOOLS / ACCESS / DATA
→ IDENTIFY FAILURE / RECOVERY PATHS
→ CHECK REAL-TIME STATE
→ PLAN
→ REUSE
→ INTEGRATE
→ PARTNER
→ BUILD ONLY WHEN JUSTIFIED
→ TEST
→ VERIFY
→ RECORD EVIDENCE
→ COMPOUND
```

## Layer boundary

```text
LAW      = WHAT MUST BE TRUE
MEMORY   = WHAT DURABLY MATTERS
RUNTIME  = WHAT IS TRUE / HAPPENING NOW
EVIDENCE = WHY A CLAIM IS TRUSTED
ARCHIVE  = HISTORICAL SOURCE MATERIAL
```

## Inheritance rule

Every APEX repository governed by these laws inherits the canonical law set. Local rules may add stricter requirements but may not weaken canonical requirements.

## Promotion rule

The staged law package becomes the standalone canonical repository source when `APEX-Laws` is created. No claim of standalone repository creation is made until GitHub reports that repository as existing.

Until then, `Apex-Hub/docs/canonical/` is the authoritative staging source for the pending standalone law package.
