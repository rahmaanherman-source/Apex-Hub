## Inheritance rule

Every APEX repository governed by these laws inherits the canonical law set. Local rules may add stricter requirements but may not weaken canonical requirements.

## Promotion rule

The staged law package becomes the standalone canonical repository source when `APEX-Laws` is created. No claim of standalone repository creation is made until GitHub reports that repository as existing.
