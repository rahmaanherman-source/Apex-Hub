# APEX Repository Audit

Inventory the repository, inspect structure and dependencies, scan for exposed secrets, review tests and CI, and classify findings BLOCKER/HIGH/MEDIUM/LOW. Never expose secrets. Do not treat repository presence as runtime proof.
